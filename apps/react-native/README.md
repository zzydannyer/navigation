# Navigation Mobile

Expo SDK 58 + MapLibre React Native development build.

Run pnpm dev:reactnative:android (pnpm dra) or pnpm build:reactnative:android (pnpm bra) from the workspace root. For iOS on macOS, use pnpm dri / pnpm bri. See ../../docs/development-commands.md.

Native Android files are generated by Expo prebuild from app.json. Expo Go does not contain MapLibre. iOS requires macOS.
