## 一、调研结论摘要（关键结论均带来源，详见调研报告）

1. **专业海图 SDK 候选格局**：
   - **Teledyne SevenCs Nautilus Maritime SDK**（SevenCs 已被 Teledyne 收购；注意：SevenCs 与 IIC Technologies 是两家公司）：官方页面明确 S-57 + S-100 体系（S-101/S-102/S-104/S-111），ECDIS 级 S-52 显示定位，提供 **60 天试用**。但**官网未列出 Android/iOS 支持**【未确认，P1 头号询价问题】；S-63 运行时解密与安全水深/主题等能力需询价确认【未确认】。来源：https://www.sevencs.com/products/maritime-sdk/nautilus-maritime-sdk
   - **Esri ArcGIS Maps SDK**（原 Runtime）：Android/iOS 双端官方文档明确支持 **S-57 ENC 显示（S-52 规范）、S-63 加密 ENC、base+update 交换集、点选**；**S-101 设备端显示未见文档支持**【未确认，倾向不支持】；无官方 RN 绑定；ENC 图层至少需 Standard 许可档。来源：https://developers.arcgis.com/android/layers/display-electronic-navigational-charts/ 、https://developers.arcgis.com/swift/layers/display-electronic-navigational-charts/
   - **GDAL/OGR**：仅 S-57 只读解析（自动应用更新），无 S-52 显示规则、无 S-63、无 S-101；只能做解析与验收对照。来源：https://gdal.org/en/stable/drivers/vector/s57.html 、GDAL 邮件列表确认无 S-63（https://gdal-dev.osgeo.narkive.com/wAS9TLg6/reading-s-63 ）
   - **OpenCPN（GPLv2+）**：S-57 + S-52 显示、S-63 插件（o-charts）；S-101【未确认/现状不支持】；GPL 传染性使其不能直接嵌入闭源应用，定位为开源验收基准（oracle）。来源：https://opencpn.org/ 、https://o-charts.org/manuals/s63_index.php
   - **IIC / dKart / Wärtsilä-Transas**：均无对外可嵌入的移动显示 SDK【未确认有移动运行时】，IIC 的免费 S-101 Viewer 可作 S-101 数据对照工具。
2. **标准现状**：S-101 当前 **Edition 1.1.0**，IHO 明确"仅用于实现与测试"（https://registry.iho.int/productspec/view.do?idx=195&product_ID=S-101 ）；S-63 由 IHB 任 Scheme Administrator 签发 OEM 证书，加密为 Blowfish/ECB（S-100 Part 15 用 AES）（https://www.iho-ohi.net/english/about-encs/enc-data-protection/s-63-faq.html ）。
3. **MapLibre / PMTiles**：MapLibre Native 自 Android 11.7+/iOS 6.10 原生支持 PMTiles（`pmtiles://` 前缀）；`@maplibre/maplibre-react-native` 11.5.1 锁定原生 Android 13.6.1 / iOS 6.31.0，**已包含 PMTiles 能力**。来源：https://maplibre.org/news/2025-02-03-maplibre-newsletter-january-2025/ 、https://github.com/maplibre/maplibre-react-native/releases

## 二、ADR-001：海图引擎路线（草案，未冻结）

- 状态：**Proposed**。P1 真机验证通过前**不锁定任何路线**，尤其不锁定自研全格式海图核心。
- 决策（推荐验证顺序）：
  1. **优先向 Teledyne SevenCs 提交 Nautilus 60 天试用申请**，书面确认四点：① Android/iOS 是否有构建；② S-63 运行时解密；③ S-101 Edition 1.1 支持；④ OEM 报价模式。若移动端不支持 → 降级。
  2. **同时注册 Esri ArcGIS Maps SDK 开发者**，用 NOAA 免费 S-57（CC0）与 S-63 测试数据做 Android/iPad 双端对照验证（显示/点选/更新），并询问 S-101 路线图。短板：S-101 不上设备、ENC 需 Standard 档报价。
- 主渲染方案决策树（写入能力边界）：SDK 自有原生视图（首选）→ 可嵌入渲染器 → 合法数据输出；**不假设可叠两层 GPU 视图**；业务图形叠加与事件映射按 SDK 实测。MapLibre 继续承担适合它的底图与业务图层，叠加方式以实测为准。
- 无合适 SDK 时的备选路线（**未启用**）：先交付 S-57 辅助显示（GDAL 只承担数据读取；S-52 显示与安全语义需独立实现）+ PMTiles；S-63 与 S-101 保持明确未交付。自研路线的成本与显示规则缺口需另行单列。
- 退出方案：Nautilus 移动端不可用 → ArcGIS（接受 S-101 缺位）→ 自研（S-57+PMTiles 先行）。
- 许可与成本来源：SevenCs 试用表单（产品页）、Esri 开发者注册与 Standard 档报价、PRIMAR（https://www.primar.org/about-primar ）与 IC-ENC 的 RENC 数据合同。**凭据与报价单不进仓库**。
