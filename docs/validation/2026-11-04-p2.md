## 结果

### 平板自适应布局
- `app.json` orientation 改为 `default`，允许横竖屏旋转。
- `useResponsiveLayout()` 基于 `useWindowDimensions` 宽度，760px 断点；宽屏 = 地图 + 右侧 320px 可折叠侧栏，窄屏 = 底部面板（与 P0 一致）。
- ChartScreen 已接入；RouteScreen / InstrumentScreen 保持窄屏单页行为（最小改动原则，宽屏时内容居中拉伸，未做侧栏拆分）。
- 安全区通过 `useSafeAreaInsets()` 应用；触控目标 ≥48pt。
- 相机状态通过 `useRef<CameraRef>` 保留，旋转不重建。

### chart-core 包
- 类型：`ChartSourceKind`（S57/S63/S101/PMTILES）、`ChartDataset`、`ChartCapabilities`、`ChartErrorCode`。
- 能力声明：PMTILES 声明 read/offline/display；S57/S101/S63 声明为空（未实现显示引擎）。
- 错误码：CORRUPTED/UNSUPPORTED/MISSING_UPDATE/AUTH_REQUIRED/DISK_FULL/CANCELLED/DUPLICATE/RUNTIME。
- 导入状态机：纯函数 `IDLE → VALIDATING → IMPORTING → COMMITTING → READY`，失败路径清理 temp；7 个 vitest 用例覆盖取消/失败清理/原子提交/重复导入/断电恢复。
- 15/15 测试通过。

### PMTiles
- 纯 TS v3 reader：127 字节 header 解析、列式目录解码（tileId delta + runLength + length + offset 分四列）、Hilbert 曲线 zxy→tileId、offset=stored-1（0=继承上一条目）、随机访问瓦片（不整档重读）。
- 真实样例验证：Protomaps Basemap Firenze 6.6MB（ODbL），header（spec v3, MVT, gzip, z0-15, 覆盖 11.22-11.29°E/43.74-43.79°N）、metadata（12 个 vector_layers）、瓦片查找（z0=805KB MVT, z1=652KB MVT）全部正确。
- **选型结论**：原生 `pmtiles://` 为选定路径。maplibre-react-native 11.5.1 锁定原生 Android 13.6.1 / iOS 6.31.0，均高于 pmtiles 支持阈值（Android 11.7+/iOS 6.10）；JS 层 VectorSource/RasterSource 的 `url` 字段自由字符串透传原生。纯 TS reader 用于离线验证，不引入回环 HTTP 服务。
- 地图渲染接入：通过 `<VectorSource url="pmtiles://...">` 传入（设备上未验证，标"未验证"）。
